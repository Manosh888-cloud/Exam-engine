Expected questions.json format

Keep question data in this JSON file, completely separate from the app itself. Any chapter that follows this schema will load without touching the HTML.

{ "examTitle": "Cardiology - Chapter 4", "mcq": [ { "id": "c4-q1", "question": "Which vessel supplies the SA node in most people?", "options": [ "Right coronary artery", "Left anterior descending artery", "Circumflex artery", "Great cardiac vein" ], "correctIndex": 0, "explanation": "In ~60% of people the SA node is supplied by the RCA." } ], "written": [ { "id": "c4-w1", "question": "Describe the pathophysiology of atrial fibrillation.", "answer": "Disorganized atrial electrical activity from multiple re-entrant wavelets / ectopic foci, leading to loss of coordinated atrial contraction...", "keywords": [ "re-entrant|reentry|re-entry", "ectopic foci|ectopic", "loss of atrial contraction|loss of coordinated contraction" ] } ] }

Rules: mcq and written arrays are both optional but at least one must contain items. Each MCQ needs question, an options array (2-5 items) and a valid correctIndex. Each written question needs question and answer. A written question may also have an optional keywords array (3-6 items): each item is one key point, and you can list accepted synonyms in the same string separated by |. Keywords are matched automatically against your typed answer and double as a self-grading checklist (all keywords are worth the same). id is optional — one is generated automatically if missing.
